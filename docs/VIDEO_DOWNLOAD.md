# Исправление получения видео — 3 октября 2026

Регрессионным тестом воспроизведена ошибка: общий фильтр секретов принимал `xai-vidgen-bucket` и `xai-video-<UUID>` в `video.url` за ключ. Клиент получал повреждённую ссылку с `[redacted]`, поэтому CDN отвечал 404. Ошибка CORS скрывала тело этого ответа. Статус `done` в JSON сам по себе не подтверждал, что браузер получил файл.

Фильтр теперь сохраняет только известные сегменты пути официального HTTPS-хоста vidgen.x.ai. Секреты в query, Bearer-токены, другие ключи и явно переданный секрет по-прежнему удаляются. Добавлен тест с реальным форматом URL из документации xAI.

Для обеих видеомоделей клиент после завершения задания получает файл через `/api/grok?action=download&request_id=…`. Сервер требует сессию и same-origin-проверку, проверяет принадлежность задания, повторно получает статус xAI и использует только возвращённый API адрес. Произвольную URL клиент передать не может. Разрешены только HTTPS vidgen.x.ai и files-cdn.x.ai без credentials/нестандартного порта; редиректы запрещены. Ключ отправляется только api.x.ai. Скачивание ограничено 256 MiB, 120 секундами и существующими лимитами параллельных запросов. Ответы не кэшируются.

Кратковременный 404 повторяется до трёх попыток с паузой 1 с. Проверяются размер и MP4 file-type box; HTML и пустой ответ не выдаются как видео. Реальный 404 после повторов передаётся как ошибка с возможностью повторить проверку request_id. Платная генерация автоматически не повторяется. Статус `done` при недоступном файле не приводит к клиентскому SUCCESS.

Полученный MP4 хранится в Blob браузера: воспроизведение и скачивание не требуют CORS CDN или новых загрузок временной ссылки. Blob URL освобождается при смене результата/модели и закрытии компонента. «Копировать» сохраняет исходную ссылку; «Открыть» открывает уже скачанный Blob. Ошибка декодирования браузером отражается в интерфейсе и журнале.

По [документации xAI](https://docs.x.ai/developers/model-capabilities/video/generation), URL видео временные. Этот код не является постоянным хранилищем: нужные видео следует сохранить на устройство. Перезапуск приложения удаляет сессии и принадлежность старых заданий; восстановление задания из другой сессии запрещено.

Проверки: 59 тестов прошли, включая неповреждённый URL, получение бинарного MP4 без передачи ключа CDN, чужое задание, запрещённый хост, HTML/пустой/слишком большой ответ, временный/постоянный 404 и отказ клиента от ложного успеха. ESLint, TypeScript и production-сборка прошли. Проверки использовали имитацию ответов xAI, без платной генерации. Конкретный файл из сообщения пользователя не проверялся: его полный URL скрыт.
